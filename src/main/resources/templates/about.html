О программе

Приложение
Название
Учёт заявок в service desk
Назначение
Учёт заявок сотрудников во внутренней службе поддержки: инциденты, отказы оборудования, запросы на обслуживание и доступ
Версия
1.0.0
Мониторинг
/actuator/health, /actuator/info
Разработчик
Автор
Кодрик В.Ю. — курсовой проект
Стек
Java 21, Spring Boot 4 (Web MVC, Security, Data JPA, Validation, Actuator), H2, Thymeleaf, Lombok
База данных
H2 в файловом режиме, ведение журнала — logs/app.log
Роли пользователей
  • READ_ONLY (Только просмотр) — просмотр заявок и категорий без изменения данных. выдаётся всем новым пользователям при регистрации.
  • USER (Пользователь) — создание и редактирование своих заявок, просмотр статистики по своим данным.
  • ADMIN (Администратор) — полный доступ ко всем заявкам, управление справочником категорий и ролями пользователей.
